# Novoptel PM1000 Polarimeter & EPS1000 Scrambler — Usage Guide

This document describes how the Novoptel **PM1000** polarimeter (the reference in the
calibration) and the Novoptel **EPS1000** polarization scrambler are controlled from
Python in this repository. It is the reference for the calibration scripts:
`fused_acquisition_controlled.py`, `referenced_calibration_lsq.py`,
`reading_pm1000.py` and `measure_trajectory.py`.

There are **two** supported ways to talk to the PM1000:

1. **`Python_USB` MATLAB-Compiler-SDK bridge** (primary, used by the calibration code).
   A vendor-compiled Python package wrapping the Novoptel MATLAB drivers; requires the
   **MATLAB Runtime R2021a (9.10)**.
2. **Pure-Python serial/LAN driver** (`pm1000.py`). Talks directly over USB 2.0
   (virtual COM, ASCII) or LAN (TCP, binary). No MATLAB Runtime required.

All **PM1000** register addresses below are **physical addresses** (`512 + offset`).
**EPS1000** registers use the raw offset (no `512`).

---

## 1. Stokes registers and decoding

The PM1000 exposes the Stokes vector (normalised to 1 µW) through eight 16-bit registers:

| Register (physical) | Name    | Description |
|---------------------|---------|-------------|
| 512 + 10            | S0uWU   | S0 (power) integer part, µW |
| 512 + 11            | S0uWL   | S0 fractional part (updated after reading S0uWU) |
| 512 + 12            | S1uWU   | S1 integer part, offset-binary (offset = 2^15 = 32768) |
| 512 + 13            | S1uWL   | S1 fractional part (updated after reading S1uWU) |
| 512 + 14            | S2uWU   | S2 integer part, offset-binary |
| 512 + 15            | S2uWL   | S2 fractional part |
| 512 + 16            | S3uWU   | S3 integer part, offset-binary |
| 512 + 17            | S3uWL   | S3 fractional part |

**Decoding** (this is what every script in this repo does):

```python
S0 = S0_int + S0_frac / 65536.0
S1 = (S1_int - 32768) + S1_frac / 65536.0
S2 = (S2_int - 32768) + S2_frac / 65536.0
S3 = (S3_int - 32768) + S3_frac / 65536.0
```

Notes:
- **S0** is unsigned (no offset); its fractional part is a 16-bit fraction → `/ 65536`.
- **S1..S3** are offset-binary: the integer part is signed as `raw − 32768`. Their
  fractional part is **also** a 16-bit fraction → `/ 65536` (not `/ 32768`).
- Read the integer register **before** its fractional register (the fractional value is latched when the integer part is read).
- Degree of polarisation: `DOP = sqrt(S1² + S2² + S3²) / S0`.

## 2. Interface A — `Python_USB` MATLAB bridge (used by the calibration scripts)

### 2.1 Prerequisites

- Install **MATLAB Runtime R2021a (9.10)**:
  <https://de.mathworks.com/products/compiler/matlab-runtime.html>
- The vendor-provided `Python_USB` package (see `Python_USB_Support_Files/`).
- The Python `matlab` module (bundled with the MATLAB Runtime Python integration).

```python
import Python_USB
import matlab            # for matlab.uint16 / matlab.double
```

### 2.2 Lifecycle

```python
dev = Python_USB.initialize()     # start the MATLAB Runtime (once)

# ... init / read / write ...

dev.closepm(); dev.closeeps()     # release devices
dev.terminate()                   # stop the MATLAB Runtime
```

> The MATLAB Runtime leaks array wrappers in long loops. The calibration scripts call
> `gc.collect()` every few measurements and pre-create the `matlab.double` address
> arrays to avoid crashes (see `fused_acquisition_controlled.py`).

### 2.3 PM1000 (reference polarimeter)

```python
def addr(a):
    return matlab.double([a], size=(1, 1))

PM_DESCR = "PM1000-100M-XL-FA-N20-D 82"     # device-specific descriptor
ok, diagnosis, handle, in_descr, out_descr = dev.initpm(
    matlab.uint16([3]), PM_DESCR, nargout=5)   # [3] = USB 3.0, [2] = USB 2.0
if not ok:
    raise RuntimeError(f"PM1000 init failed: {diagnosis}")

# Averaging-time exponent (ATE): 2^ATE samples averaged per read.
dev.writepm(addr(512 + 1), matlab.uint16([ate], size=(1, 1)))

# Disable external BNC triggering (safe default).
dev.writepm(addr(512 + 92), matlab.uint16([0], size=(1, 1)))

# Read one register -> (value, ok)
val, ok = dev.readpm(addr(512 + 10), nargout=2)
```

PM1000 registers used in this repo:

| Register (physical) | Meaning |
|---------------------|---------|
| 512 + 1   | Averaging-time exponent (ATE): averages `2^ATE` samples |
| 512 + 10 … 17 | Stokes vector (see §1) |
| 512 + 45  | S3 sign setting (read) |
| 512 + 92  | Trigger mode (write `0` = disable external trigger) |
| 512 + 226 | BNC trigger debounce/delay (`0` = minimum) |

### 2.4 EPS1000 (scrambler)

```python
EPS_DESCR = "EPS1000-20M-CL-S-LU-NN-D 332"    # device-specific descriptor
ok, diagnosis, handle, in_descr, out_descr = dev.initeps(
    matlab.uint16([2]), EPS_DESCR, nargout=5)   # [2] = USB 2.0

# Stop rotation of all waveplates so the SOP holds still (stable-SOP mode).
for reg in range(0, 7):           # rotation enable/direction: HWP + QWP0..QWP5
    dev.writeeps(addr(reg), matlab.double([0], size=(1, 1)))

# Write random 16-bit positions -> random stable SOP.
import random
for reg in range(40, 47):         # position index: HWP + QWP0..QWP5
    dev.writeeps(addr(reg), matlab.double([random.randint(0, 0xFFFF)], size=(1, 1)))
```

EPS1000 registers used in this repo:

| Register | Meaning |
|----------|---------|
| 0 … 6   | Rotation enable/direction for HWP + QWP0…QWP5 (write `0` = stop) |
| 40 … 46 | Position index for HWP + QWP0…QWP5 (16-bit, `0..0xFFFF`) |
| 23, 24  | Mode / speed (read-only diagnostics) |

### 2.5 Device descriptors

The descriptor string identifies the specific unit. Examples seen in this repo:
- PM1000 (USB 3.0): `"PM1000-100M-XL-FA-N20-D 82"`, `"PM1000-100M-XL-FA-NN-D 44"`
- EPS1000: `"EPS1000-20M-CL-S-LU-NN-D 332"`

Replace these with the string printed for your own unit.

## 3. Interface B — pure-Python serial/LAN driver (`pm1000.py`)

`pm1000.py` is a standalone driver that does **not** need the MATLAB Runtime.

```bash
python pm1000.py --interface usb --port COM3 --n 20 --interval 0.2
python pm1000.py --interface lan --ip 192.168.1.100 --n 20 --interval 0.2
```

### 3.1 USB 2.0 (serial, ASCII)

- Settings: baud 230400, 8 data bits, 1 stop bit, no parity.
- Commands end with `\r`.
- Write: `W` + 3 hex address digits + 4 hex data digits + `\r`  →  e.g. `W00A1234\r`.
- Read:  `R` + 3 hex address digits + `0000` + `\r`  →  response is 4 hex digits + `\r`.

### 3.2 LAN (TCP, binary)

- Port **5025**.
- Write packet: `0x57` + 2-byte address (MSB first) + 2-byte data (MSB first) = 5 bytes.
- Read request: `0x52` + 2-byte address = 3 bytes; response is 2-byte data (MSB first).

The class in `pm1000.py` already implements `read_stokes()`, `read_stokes_uw()`,
`read_stokes_normalized()` and register read/write for both interfaces.

## 4. Practical notes and gotchas

- **Read order**: always read the integer register before its fractional register.
- **Stable SOP**: the EPS1000 waveplates must have rotation disabled (regs 0–6 → 0) for the SOP to hold still while the scope and PM1000 are read.
- **Matched integration windows**: the scope window and the PM1000 ATE should cover the same integration time (`fused_acquisition_controlled.py` computes `ate = round(log2(window / 10 ns))`).
- **Long runs**: call `gc.collect()` periodically and reuse `matlab.double` arrays to avoid the MATLAB Runtime leaking memory and crashing.
- **Close before switching**: devices must be closed (`closepm` / `closeeps`) before other software can access them.
